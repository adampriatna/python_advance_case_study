Studi Kasus 1 — Analisis Nilai Mahasiswa

Deskripsi

Program ini digunakan untuk menganalisis nilai mahasiswa berdasarkan nilai tugas, UTS, dan UAS. Program menghitung nilai akhir, menampilkan mahasiswa berprestasi, mengurutkan ranking, dan menentukan mahasiswa terbaik.

Bobot Penilaian

- Tugas: 30%
- UTS: 30%
- UAS: 40%

Konsep Python yang Digunakan

- List Comprehension: menghitung dan mengolah data mahasiswa.
- Lambda Function: menentukan kunci pengurutan nilai.
- Filtering: memilih mahasiswa dengan nilai akhir di atas 80.
- Sorting: mengurutkan mahasiswa dari nilai tertinggi ke terendah.
- Enumerate: memberikan nomor urut ranking.

Cara Menjalankan

1. Pastikan Python sudah terpasang.
2. Buka terminal pada folder "case-01-analisis-nilai".
3. Jalankan perintah berikut:

python main.py

Hasil Program

Program menampilkan nilai akhir seluruh mahasiswa, daftar mahasiswa berprestasi, ranking mahasiswa, dan mahasiswa terbaik.

Bukti eksekusi dapat dilihat pada file "output.png" di folder ini.
