Deskripsi Proyek

Proyek ini berisi penyelesaian tiga studi kasus Python Advanced Topics yang menerapkan konsep pemrograman lanjutan.

Daftar Studi Kasus

1. Analisis Nilai Mahasiswa

Menghitung nilai akhir mahasiswa berdasarkan bobot tugas 30%, UTS 30%, dan UAS 40%. Program menampilkan mahasiswa dengan nilai di atas 80 serta menyusun peringkat berdasarkan nilai akhir.

Konsep: List comprehension, lambda, filter, dan sorting.

2. IoT Sensor Generator

Mensimulasikan pembacaan suhu sensor IoT secara bertahap dan mengelompokkan suhu menjadi Dingin, Normal, atau Panas.

Konsep: Generator, "yield", "next()", dan efisiensi memori.

3. Login Security dan Audit Log

Menerapkan validasi username dan password serta pencatatan aktivitas login, termasuk pengujian login gagal dan berhasil.

Konsep: Class, object, property, regular expression, decorator, dan exception handling.
